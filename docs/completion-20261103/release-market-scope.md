# Release market scope

The setup form requires an explicit business country and reporting currency.
Neither IP geolocation nor a Sweden/SEK fallback silently creates a financial policy.
The initial fiscal-month suggestion is January and changes to the selected
country's existing suggestion; the user can review and change it.

The current shipped UI language is English. Locale controls number/date presentation;
it is separate from business country, reporting currency and the applicable law.
Existing multi-currency calculation behavior, explicit invoice tax settings and
manual payments remain available without implying country-specific certification.

Before public commercial signup the operator must supply its legal name/contact,
approved terms/privacy, permitted markets and any mandatory invoice fields/rules.
No source edit can create the missing legal identity or provider contract.
Current public signup and unconfigured payment/bank/email products remain gated.
This records the technical scope; it is not a legal or accounting opinion.
